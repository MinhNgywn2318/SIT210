## Description
This project demonstrates a simple GUI-based smart home lighting control system using Raspberry Pi, Python Tkinter, and three LEDs.

## Hardware
- Raspberry Pi 4
- 3 LEDs
- 3 resistors
- Breadboard
- Jumper wires

## Software
- Python 3
- Tkinter
- RPi.GPIO

## Function
The GUI contains three radio buttons for Living Room, Bathroom, and Closet, and one Exit button. When the user selects a room, the corresponding LED turns on while the other two LEDs remain off.
