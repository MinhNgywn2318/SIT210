## Overview
This project extends the GUI developed in Task 5.1P by allowing the user to control the brightness of an LED using PWM on a Raspberry Pi. The LED represents a living room light.

## Hardware Used
- Raspberry Pi
- LED
- 220 ohm resistor
- Breadboard
- Jumper wires

## Software Used
- Python 3
- Tkinter
- RPi.GPIO

## Features
- Turn LED ON
- Turn LED OFF
- Adjust brightness using a slider
- Real-time PWM brightness control

## GPIO Connection
- GPIO 18 -> resistor -> LED anode
- LED cathode -> GND

## How to Run
python3 task5_2_gui.py
